# 师门 ShiMen - 便携版发布目录

本仓库发布的是师门 Windows 便携版的目录结构、默认配置与技能资源，**不是**开发源码仓库。

## 使用方式

1. 从发布页下载完整的便携版压缩包并解压到一个普通目录。
2. 保持目录结构完整，不要单独移动 `core`、`CDXAgent` 或 `tools`。
3. 双击 `Lmentor.exe` 启动。
4. 首次启动后，根据界面提示填写名称、师门名称和模型供应商配置。

## 目录说明

- `Lmentor.exe`：便携版启动器。
- `core/`：打包后的应用运行时。
- `CDXAgent/`：可编辑的模型配置、技能和运行时支持文件。
- `tools/`：便携版辅助工具。
- `START.txt`：简明启动说明。

## 本地数据与隐私

仓库和发布包不包含用户的 API Key、登录认证、聊天记录、项目记录、运行日志或缓存。应用运行后会在本机创建这些私有状态；请勿将这些文件提交到公开仓库。

## 运行时说明

`CDXAgent/bin/codex.exe` 不纳入普通 Git 仓库历史。完整便携版会通过发布资产提供所需运行时；如手动维护目录，请按官方运行时分发渠道将其放入对应目录。

更多发布结构约定见 [PORTABLE_PACKAGE.md](PORTABLE_PACKAGE.md)。
